In % mode, the number is how much of the original to keep, so 70 means 70% of the width. Percent only shrinks.

Seam carving changes one dimension at a time. If you shrink both, Caire first scales the whole photo down to the right aspect, then carves the rest. Square crops to the shortest edge, so it needs both values.

Edge detection

Softens the photo before Caire looks for edges. Higher values smooth over fine texture like grass or noise, so seams pass through it more easily.

Resize a photo by removing what nobody will miss.

Seam carving looks for the least noticeable path of pixels running through an image, a seam, and removes it. It repeats that hundreds of times, so empty sky and plain walls shrink while people and edges keep their shape. Load a photo, pick a new width or height, and watch Caire carve it live.

JPEG, PNG, BMP or GIF, up to 25 MB and 40 megapixels. You can also drop a file or paste one.
